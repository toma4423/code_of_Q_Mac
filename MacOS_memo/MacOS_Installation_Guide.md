# MacOSユーザー向けインストールガイド

## 1. ダウンロード後の初期設定

Google Driveからダウンロードしたファイルには、MacOSのセキュリティ機能により制限が付加されています。
以下の手順で制限を解除してください：

```bash
# 1. ターミナルを開く（Command + Space でSpotlightを開き、「ターミナル」と入力）

# 2. ダウンロードしたファイルのディレクトリに移動
cd ~/Downloads   # 通常のダウンロード先の場合

# 3. 拡張属性を削除
xattr -cr コードのQちゃん.tar.gz

# 4. ファイルを解凍
tar -xzf コードのQちゃん.tar.gz

# 5. アプリケーションの拡張属性も削除
xattr -cr dist/コードのQちゃん.app
```

## 2. アプリケーションの実行

初回起動時は以下の手順で行ってください：

1. Finderで`dist`フォルダを開く
2. `コードのQちゃん.app`を右クリック（または Control + クリック）
3. 「開く」を選択
4. 警告が表示されたら、再度「開く」をクリック

## 3. トラブルシューティング

### 「壊れています」というエラーが表示される場合
- 上記の手順1の拡張属性削除を実行してください
- それでも解決しない場合は、以下のコマンドを試してください：
```bash
sudo xattr -cr dist/コードのQちゃん.app
```

### カメラへのアクセス許可
- 初回起動時にカメラへのアクセス許可を求められます
- 「許可」を選択してください
- 後から変更する場合は「システム環境設定」→「セキュリティとプライバシー」→「カメラ」から設定可能です

## 4. 注意事項

- MacOS 10.13.0以降が必要です
- インストール時は管理者権限が必要な場合があります
- アプリケーションフォルダにコピーして使用することを推奨します
